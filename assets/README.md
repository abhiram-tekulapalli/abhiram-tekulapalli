# Profile assets

Files used by the profile README and kept here so they can be reused in a portfolio or résumé:

| File | Purpose |
| --- | --- |
| `header.gif` | Original, locally hosted animated terminal banner. |
| `header-static.png` | Reduced-motion and static preview version of the banner. |
| `header-art.png` | Editable source artwork for future header variations. |
| `brand-mark.png` | Standalone cyan/violet geometric identity mark. |
| `footer.svg` | Lightweight vector footer motif. |
| `profile-preview.svg` | A compact visual map of the README's content and hierarchy. |

The README uses [Skill Icons](https://skillicons.dev/) for the compact technology rows, [Shields.io](https://shields.io/) for social links, a repository-owned GitHub Actions workflow for statistics cards, and [Platane/snk](https://github.com/Platane/snk) for the contribution animation.

The banner is a local alternative created from original artwork and a subtle cursor animation. RyMe's editor was inspected, but its export did not complete, so the README does not claim a RyMe export.
